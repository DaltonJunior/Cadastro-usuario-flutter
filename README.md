# Cadastro de Usuário em Flutter

Projeto desenvolvido para a atividade prática da disciplina de Desenvolvimento Mobile — Flutter e Dart.

## Objetivo

Implementar um formulário de cadastro de usuário utilizando Flutter, com campos de entrada, filtros de digitação, validações e feedback visual.

## Funcionalidades

- Cadastro com nome completo e e-mail.
- Entrada numérica para CPF e telefone.
- Validação de senha com mínimo de 6 caracteres.
- Confirmação de senha.
- Opção para mostrar ou ocultar a senha.
- Mensagens de erro abaixo dos campos inválidos.
- SnackBar de sucesso após a validação.

## Tecnologias Usadas

- Flutter
- Dart

## Como executar

1. Instale e configure o Flutter.
2. Clone este repositório.
3. Entre na pasta do projeto.
4. Execute `flutter pub get`.
5. Execute `flutter run`.
